# Standard type library

`line_types.csv` and `transformer_types.csv` are copied verbatim from **PyPSA
1.2.4** (`pypsa/data/standard_types/`), which is MIT-licensed. They are the 59
line types and 14 transformer types a fresh `pypsa.Network()` is born with.

They are here because no PyPSA network export contains them.
`export_to_csv_folder` drops exactly these rows — `export_standard_types`
defaults to false — since PyPSA's own reader repopulates them from the installed
package. A reader outside Python cannot, and `scigrid-de` is unreadable without
them: all 852 of its lines carry `x = 0` and a type name.

PyPSA in turn credits each row's source in its `references` column, mostly
pandapower and the German textbook literature; those attributions are preserved
in the files.

Regenerated by `reference/generate_goldens.py`, which writes the same tables into
`reference/goldens/standard_types/`. `StandardTypesSuite` compares this copy
against that one cell by cell, so the two cannot drift.
